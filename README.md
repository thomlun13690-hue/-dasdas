# Lumière — Artistic & Healing Portfolio

A responsive, editable one-page portfolio inspired by the provided **Artistic & Healing** visual direction.

## Included
- `index.html` — content + structure
- `styles.css` — cream / sage / warm-gray art-book styling
- `script.js` — scroll reveal + browser Edit Mode with localStorage
- `.nojekyll` — GitHub Pages friendly

## Edit without coding
Open the site, click **Edit mode**, change the highlighted text, then click **Save changes**. The text is saved in your browser via localStorage.

## Edit the design/code
Open `index.html`, `styles.css`, or `script.js` in GitHub's web editor or VS Code. Replace the Unsplash image URLs in `styles.css` with your own artwork URLs whenever you are ready.

## Publish on GitHub Pages
1. Create a GitHub repository, e.g. `artistic-healing-portfolio`.
2. Upload all files from this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`.
4. Save. GitHub will provide the live Pages URL.
